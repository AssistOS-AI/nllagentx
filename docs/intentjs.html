IntentJS in Detail

IntentJS states what one task asks the semantic runtime to do. It combines explicit instruction precedence, profile and pack constraints, concerns, target text, outputs, evidence policy, assurance, exclusions, resources and the fallback used when selection remains unclear.

Resolution precedence

  1. Explicit CLI and system restrictions.
  2. Task IntentJS declarations.
  3. Agent default and selected profile.
  4. Cheap lexical and already-materialized semantic signals.
  5. Declared fallback, normally all compatible within loaded packs.

Program shape

export default intent("review-contradictory-rules")
  .mode(analyze())
  .concerns(concern("RuleContradictionReview"))
  .outputs(findings(), structuralTrace())
  .evidence(sourceGrounded(), interpretationRobust())
  .assurance(concreteExecution(), symbolicDecisionCoverage())
  .whenUnclear(allCompatible())
  .seal();

Signal inference can advise the coding agent and planner, but it does not silently author the canonical module. Presentation directives are imported from the CNL surface and passed through .present(...). The complete generated intent for each concrete source is shown in the four tutorial pages.

Predefined values and semantic distinctions

These values are part of the DSL contract. They remain distinct during planning, execution, response composition and replay.

DomainValue(s)Meaning and boundary
Operationanalyze / validate / compare / explain / repair / canonicalizeSelects an analysis-shaped request without fabricating a target finding.
Operationgenerate / plan / analyze-and-plan / summarize-semantically / ask-for-clarificationSelects generation, planning, semantic summary or clarification behavior.
Primary outputmarkdown-cnlRequires the tagged human-readable response written to results/response.md.
Technical/semantic outputfindings / cnl-observations / composition-plan / structural-trace / repair-frames / clarification-questionsSelects typed underlying artifacts; these do not replace the primary Markdown answer.
Fallbackall-compatibleRuns every provider compatible with the loaded profile when the intent does not narrow selection.
Domain moderequire / prefer / allow / exclude / infer-from-sourceControls pack selection while keeping explicit requirements above inferred source signals.
